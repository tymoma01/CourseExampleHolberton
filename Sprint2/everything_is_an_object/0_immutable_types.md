# Python Mutable & Immutable Types

## Immutable
* `int`, `float`, `complex`, `bool`
* `str`
* `tuple`
* `frozenset`
* `bytes`

## Mutable
* `list`
* `dict`
* `set`
* `bytearray`

> **Tip:** if it's a container you can modify in-place (`append`, `update`, `add`, etc.), it's mutable. The one that trips people up is `tuple` — it looks like a list but is immutable. And `frozenset` is just the immutable twin of `set`.
